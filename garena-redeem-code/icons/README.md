# Icons

Thay thế các file PNG placeholder bằng icon thật của bạn.

## Kích thước yêu cầu
- `icon16.png` — 16x16 px
- `icon48.png` — 48x48 px
- `icon128.png` — 128x128 px

## Gợi ý
- Dùng màu xanh `#3b82f6` hoặc gradient giống UI dashboard
- Format: PNG với transparency
- Có thể tạo tại: https://favicon.io/icon-generator/
