# Security Policy

## 1. Supported Versions

We actively provide security updates and patches for the following versions of **Delta Bot (bot-klb)** and **DF Toolbox Extension**:

| Project Component     | Version Supported | Status                |
| --------------------- | ----------------- | --------------------- |
| Bot Delta (`bot-klb`) | `>= 1.14.0`       | ✅ Actively supported |
| DF Toolbox Extension  | `>= 1.9.0`        | ✅ Actively supported |
| Legacy Builds         | `< 1.14.0`        | ❌ Unsupported        |

---

## 2. Reporting a Vulnerability

We take the security of our users and data seriously. If you discover a security vulnerability or privacy concern, **please do NOT create a public GitHub issue**.

### Reporting Channel:

- Please report security vulnerabilities privately via GitHub Security Advisories:
  👉 [https://github.com/Pon1147/bot-klb/security/advisories/new](https://github.com/Pon1147/bot-klb/security/advisories/new)
- Or email the repository maintainer directly with full technical details.

### What to Include in Your Report:

1. Clear description of the vulnerability and attack vector.
2. Step-by-step reproduction steps or minimal proof of concept (PoC).
3. Potential impact on user data or bot infrastructure.
4. Suggested remediation if known.

---

## 3. Response and Remediation Commitment

- **Acknowledgment**: We aim to acknowledge receipt of security reports within **48 hours**.
- **Assessment & Fix**: Critical vulnerabilities (e.g., credential leaks, unauthorized token access, RBAC bypass) will be prioritized for immediate remediation within **7 days**.
- **Coordinated Disclosure**: We request that you give us reasonable time to release a patch before disclosing details publicly.

---

## 4. Responsible Research Rules

When conducting security research:

- Do **not** access, modify, or leak data belonging to other users.
- Do **not** perform Denial of Service (DoS/DDoS) attacks against the bot or external APIs.
- Do **not** violate Discord Developer Terms or applicable game platform policies.
