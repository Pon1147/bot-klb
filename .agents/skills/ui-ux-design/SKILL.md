# Pragmatic UI/UX Design

Build clean, accessible, intuitive interfaces with minimal visual clutter and zero bloat.

## Principles

1. **Content First, Clutter Last**:
   - Deliver key information immediately at the top level.
   - Use progressive disclosure (modals, dropdowns, expandables) for secondary details.

2. **Native & Component Standards**:
   - In Discord interfaces: use native components (Embeds, ActionRows, Buttons, StringSelectMenu, TextInputs).
   - In Web interfaces: use semantic HTML tags (`<dialog>`, `<nav>`, `<button>`) before importing UI component libraries.

3. **Accessibility & Clarity**:
   - Provide clear button labels and color cues (Primary, Success, Danger, Secondary).
   - Ensure readable contrast and informative error states with clear next steps.

4. **Consistency**:
   - Adhere strictly to the design patterns and tone established in the codebase.
